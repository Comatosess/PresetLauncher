# Preset Launcher

Таймерный лаунчер предустановок: собраны группы программ в пресеты, можно запустить одной кнопкой, поставить на автозапуск с Windows, свернуть в трей.

## Что внутри

- `preset_launcher.py` — основной исходник на Python + tkinter
- `PresetLauncher.spec` — файл для сборки `.exe` через PyInstaller
- `icon.ico` — иконка приложения
- `test_presets.json` — пример файла с пресетами (не личные данные)

## Как запустить

```bash
python preset_launcher.py
```

Нужны зависимости:
```bash
pip install pystray pillow
```

## Сборка в .exe

```bash
pyinstaller PresetLauncher.spec
```

## Как оно работает

- Создаёшь пресеты и добавляешь в них `.exe` с аргументами и задержкой
- Запускаешь пресет — приложения стартуют по очереди
- Можно поставить на автозапуск с Windows (через реестр)
- Окно сворачивается в трей вместо закрытия
